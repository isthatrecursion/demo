Aim: To study and implement the Agile Software Project Lifecycle using Jira.

Step 1: Create a Jira project
1. Open Jira.
2. Log in to your account.
3. Click the + beside Spaces.
4. Choose Kanban.
5. Select Use template and Team-managed, if displayed.
6. Enter Learning Jira Project Creation.
7. Click Create.

Step 2: Create tasks
1. Open Learning Jira Project Creation.
2. Open Board.
3. Click Create.
4. Enter Discuss the project with customer.
5. Click Create.
6. Repeat for Discuss with developers.
7. Move the tasks through To Do → In Progress → Done.

Step 3: Create a task with dates
1. Click Create.
2. Select Task.
3. Enter Start development on project model.
4. Assign the task to yourself.
5. Set the start date to 1 August 2026.
6. Set the due date to 30 August 2026.
7. Click Create.
If the date fields are missing, open the created task and check its available fields.

Step 4: Enable Backlog
1. Open your project.
2. Open Space settings → Features.
3. Look for Backlog.
4. Enable it if available.
5. Create a task named User Acceptance Testing.
If Backlog is not shown: Your current project configuration may not offer it in Features. Do not search endlessly; continue using the Board or List to create tasks.

Step 5: Create child tasks
1. Create a main task named Develop MOdule 2 software.
2. Open the task.
3. Click Add or Create related work.
4. Select Create subtask or Add a child work item, if available.
5. Enter Develop login submodule.
6. Create another child task named Change homepage picture.

Step 6: Create a Software Development project
1. Click the + beside Spaces.
2. Select Kanban.
3. Choose Team-managed, if displayed.
4. Enter Software Development.
5. Click Create.

Step 7: Add work types
1. Open Software Development.
2. Go to Space settings → Work types.
3. Check whether Bug and Story already exist.
4. If either is missing, click Add work type and add it.

Step 8: Create an Epic and Story
1. Open Software Development.
2. Click Create.
3. Select Epic.
4. Enter Password reset feature — type it only once.
5. Click Create.
6. Click Create again and select Story.
7. Enter the Story requirement:
As a registered user, I want to get an option to reset my password to regain access.
8. Create the Story.
9. Open the Story and find the Parent field.
10. Select Password reset feature.

Step 9: Create project tasks
Create these three tasks using Create:
1. Password Reset User Interface Design
2. Password Reset functionality using API
3. Email Configuration

Step 10: Add child tasks
Open Password Reset User Interface Design and create these three child tasks:
1. Discuss with Solution Architect and UI Designer
2. Assign Developer
3. Start Development

Step 11: Create a Bug
1. Click Create.
2. Select Bug.
3. Enter the summary:
Users are complaining that, they are getting multiple emails for password reset.
4. Click Create.
5. Move the Bug through the available workflow statuses.

Step 12: Check project progress
1. Open Software Development.
2. Click Summary to check project progress.
3. Click List to view tasks.
4. Click Calendar to explore scheduled work.

Step 13: Explore project templates
1. Click the + beside Spaces.
2. Open the project or space creation screen.
3. Explore the available templates, including Kanban, Scrum, and other displayed options.
4. Return to your existing project.

Step 14: Create a new workflow status
1. Open Software Development.
2. Go to Space settings → Work types.
3. Click Task.
4. Click Edit workflow.
5. Click Add a status.
6. Enter Deployed in Prod.
7. Click Add.
8. Save or update the workflow if prompted.
You have already reached the Add a status screen in your Jira interface, so continue from there if the status has not been saved yet.

Step 15: Create a deployment task
1. Return to the Software Development Board.
2. Click Create.
3. Enter Deployed Password Reset.
4. Click Create.
5. Move the task to Deployed in Prod.

Step 16: Create a release
A. Open Releases
1. Open Software Development.
2. Look at the top navigation tabs: Summary, Timeline, Board, Calendar, List.
3. Click the + button to the right of the tabs.
4. Select Releases, if displayed.
B. Create the release
1. Open the Releases page.
2. Click Create version, Create release, or Add version, depending on the options shown.
3. Enter:
- Name: Password reset module v1.0
- Start date: 3 August 2026
- Release date: 1 September 2026
- Description: Release date is on 1st Sept. 2026
4. Click Create or Save.
